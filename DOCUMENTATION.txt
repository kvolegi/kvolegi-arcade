1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
kvolegi arcade is a cross-platform retro-neon arcade game suite developed from
scratch to explore:
- Modular cross-platform architecture (Shared Pure Java Core + Platform UIs)
- Direct 2D rendering without relying on heavyweight third-party game engines
- Real-time memory layout, dynamic array expansion, and in-RAM board remapping
- Algorithmic threat detection for board game AI
- Slot reel mathematics with authentic Las Vegas payout curves
- Dedicated 60 FPS background thread loops on mobile
- Standalone packaging (macOS .app bundle, universal cross-platform JAR, Android APK)

Games included in the suite:
1. Tic Tac Toe (Neon Edition) - Expanding dynamic grid, 5-in-a-row rules, heuristic AI.
2. Sigma Slots - 4x5 reel matrix, 20 paylines, custom bet inputs.
3. Beer Snake - 25 progression levels, switchable toroidal wrapping vs solid walls.
4. Bobr Minesweeper - Safe-first-click generator, Sonar radar pulse, flag placement.


2. ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
A core design goal was avoiding heavy one-size-fits-all engines like Unity or Godot.
While useful for complex 3D worlds, general engines add substantial binary bloat,
high idle memory footprints, and heavy battery drain on mobile devices.

Instead, the codebase uses a clean three-tier architecture:
- Core Module:    100% Pure Java Standard Library, zero external dependencies.
- Desktop UI:     JavaFX 21 with hardware-accelerated scene graphs.
- Mobile UI:      Native Android SurfaceView with a dedicated background RenderThread.

A. Desktop (JavaFX):
1. Hardware Acceleration: JavaFX connects directly to native graphics subsystems
   (Metal/OpenGL on macOS, DirectX on Windows). This powers real-time Gaussian
   drop-shadows and neon glow pulse animations at 60 FPS with minimal CPU load.
2. Responsive Layout Hierarchy: Containers like BorderPane, VBox, and GridPane
   adapt dynamically from standard 800x600 windows up to 4K displays.
3. Event Dispatch Safety: Desktop controls set setPickOnBounds(false) to ensure
   large 50px glow shaders do not capture click events intended for adjacent buttons.

B. Mobile (Android Native SurfaceView):
1. Compact Binary: The full release APK is ~5.6 MB, roughly one-tenth the size of a
   comparable Unity or LibGDX build.
2. Thread Isolation: The game loop runs on a background worker thread (ArcadeView.java)
   that locks and unlocks the hardware canvas via double-buffering, completely
   insulating the Android OS UI thread from calculation spikes.


3. RUNNING & INSTALLATION
--------------------------------------------------------------------------------
A. Universal JAR (Windows, Linux, macOS):
   The universal desktop JAR is located at:
     builds/kvolegi-arcade-universal.jar

   Run via command line with Java 17 or Java 21+:
     java -jar builds/kvolegi-arcade-universal.jar

   Prerequisites:
   - Windows: Install OpenJDK via winget (`winget install EclipseAdoptium.Temurin.21.JRE`)
     or download an installer from adoptium.net.
   - Linux: Install JRE (`sudo apt install openjdk-21-jre` on Debian/Ubuntu,
     `sudo dnf install java-21-openjdk` on Fedora).

B. macOS Application Bundle:
   Located at:
     builds/mac/kvolegi arcade.app

   - Double-click `kvolegi arcade.app` in Finder to launch.
   - If macOS Gatekeeper blocks opening with an unverified developer warning, run:
       xattr -cr "builds/mac/kvolegi arcade.app"
     or right-click the app in Finder and choose "Open".
   - You can also launch via terminal:
       ./builds/mac/run_mac.sh

C. Android APK:
   Located at:
     builds/android/kvolegi-arcade.apk

   - Transfer the file to an Android device (API 24+ / Android 7.0 or newer).
   - Tap to install and run.


4. GAME MECHANICS REFERENCE
--------------------------------------------------------------------------------
A. Tic Tac Toe (Dynamic Expansion):
   - Starts at 5x5. When more than 50% of the cells are played, the matrix expands
     by 5 rows and 5 columns up to 25x25.
   - Center offset formula: Delta = (N_new - N_old) / 2.
   - Heuristic AI weights: Win immediate = +50,000, Block 4-in-a-row = +15,000,
     Create fork = +1,200.

B. Sigma Slots:
   - 4 rows by 5 reels with 20 distinct paylines.
   - Wild symbol substitutes for standard fruits; Scatter symbols pay independent
     of payline alignment.

C. Beer Snake:
   - 25 speed tiers scaling from 185ms down to a 60ms minimum frame tick.
   - Toggleable boundaries (fatal walls vs. toroidal coordinate wrap).

D. Bobr Minesweeper:
   - First-click safe matrix generator guarantees a zero-mine starting cell.
   - Sonar radar pulse uncovers neighboring cells without detonation risk.
