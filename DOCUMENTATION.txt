1. PROJECT OVERVIEW & ARCHITECTURAL PHILOSOPHY
--------------------------------------------------------------------------------
kvolegi arcade is an enterprise-grade, multiplatform retro-neon arcade game suite
developed from the ground up to demonstrate mastery in:
- Modern cross-platform architecture design (Shared Pure Java Core + Platform Frontends)
- Native UI performance without reliance on bloated 3rd-party game engines
- Real-time memory management, dynamic array reallocation, and in-RAM state preservation
- Algorithmic design (Minimax / Heuristic tactical threat detection AI)
- High-stakes game math (Las Vegas casino RTP slot reel payout distributions)
- Deterministic 60 FPS multi-threaded game loops on mobile
- Automated native packaging (Windows PE32 .exe via Launch4j, signed APK, macOS .app)

The application bundles four complete arcade games:
1. Tic Tac Toe (Neon Edition) - Infinite dynamic expanding board, 5-in-a-row rule, AI.
2. Sigma Slots - 4x5 reel matrix, 20 authentic paylines, Vegas slot math, custom bet modal.
3. Beer Snake - 25 curated difficulty levels, toroidal wrap-around vs fatal walls.
4. Bobr Minesweeper - Safe-first-click matrix, Sonar radar pulse, broccoli flagging.


2. CROSS-PLATFORM STRATEGY: WHY JAVAFX ON PC AND NATIVE CANVAS ON MOBILE?
--------------------------------------------------------------------------------
A key design decision in this project was avoiding heavy "one-size-fits-all" engines
(such as Unity, Unreal, or Godot). While cross-platform engines simplify development,
they impose significant trade-offs: massive binary size (30-60 MB minimum), high RAM
overhead, sluggish boot times, and heavy battery consumption on mobile devices.

Instead, kvolegi arcade employs a clean three-tier architecture:
- Core Module:    100% Pure Java Standard Library, zero external dependencies.
- PC Frontend:    JavaFX 21 with GPU hardware-accelerated scene graphs.
- Mobile Frontend: Native Android SurfaceView with a dedicated background RenderThread.

A. Why JavaFX on PC?
1. Hardware Acceleration: JavaFX binds directly to native graphics subsystems
   (DirectX on Windows, Metal/OpenGL on macOS). This enables rich visual filters
   such as real-time Gaussian drop-shadows and neon glow pulse animations at 60+ FPS
   with near-zero CPU usage.
2. Clean Reactive Layout Hierarchy: JavaFX provides robust layout containers
   (BorderPane, VBox, GridPane) with native observable properties (widthProperty,
   heightProperty). This allows the desktop application to dynamically adapt to any
   arbitrary window dimensions (800x600 windowed up to 4K Ultra-HD).
3. Zero-Overlap Hit-Testing: JavaFX controls support explicit setPickOnBounds(false)
   configuration. This ensures visual Gaussian glow effects (radius 50px) do not
   corrupt the mouse event dispatcher, guaranteeing 100% click accuracy across adjacent
   buttons.
4. Native Packaging: Fully wraps into native Windows .exe binaries using Launch4j
   (with embedded icon, version info, and JRE discovery) and macOS .app bundles.

B. Why Native Android SurfaceView on Mobile?
1. Featherlight Binary Footprint: The entire Android APK is only ~5.6 MB! A comparable
   game in Unity or LibGDX would exceed 40-50 MB.
2. Decoupled 60 FPS Game Loop: Instead of running on the Android Main UI Thread,
   all rendering and game physics execute on a dedicated background RenderThread
   (ArcadeView.java). Double-buffering via SurfaceHolder.lockCanvas() ensures zero
   frame stuttering, even during heavy GC cycles.
3. Battery Efficiency: Memory allocations inside the render loop are strictly
   zeroed through pre-allocated sprite caches, primitive coordinate calculations,
   and object pooling.
4. Native OS Modals: Interactive input dialogs (such as entering custom wagers in
   Slots) leverage native Android AlertDialogs with numerical soft keyboards,
   providing a crisp, intuitive mobile user experience.


3. TECHNICAL HIGHLIGHTS & GAME ALGORITHMS
--------------------------------------------------------------------------------

A. Tic Tac Toe: Infinite Board & In-RAM Centered Expansion
Standard Tic Tac Toe is trivial and limited to 3x3 grids. kvolegi arcade implements
an infinite dynamic board architecture:
1. Dynamic In-RAM Expansion:
   The game starts with a 5x5 board. When more than 50% of the cells are populated:
   - The current board state is captured in RAM into an oldBoard[N][N] snapshot.
   - The grid size expands by +5 (boardSize = boardSize + 5) up to 25x25.
   - The old moves are mapped into the new grid with centered coordinate offsets:
     offset = (newSize - oldSize) / 2;
     newRow = oldRow + offset;
     newCol = oldCol + offset;
   - All cell states (symbol, neon text colors, borders, effects) are preserved
     without losing player progress or resetting the game.
2. Adaptive Cell Sizing:
   On every board resize or window change, the cell dimensions are recomputed:
   maxGridH = Math.max(180, winH - 155);
   maxGridW = Math.max(180, winW - 60);
   maxBoardPx = Math.min(maxGridW, maxGridH);
   cellSize = (maxBoardPx - (boardSize - 1) * CELL_GAP) / boardSize;
   cellSize = Math.max(18, Math.min(88, cellSize));
3. Tactical Heuristic AI (Nightmare Difficulty):
   The AI scans four directional vectors:
   - Horizontal:    (row, col + 1)
   - Vertical:      (row + 1, col)
   - Main Diagonal: (row + 1, col + 1)
   - Anti-Diagonal: (row + 1, col - 1)
   For every empty cell, it evaluates threats for both player and computer:
   - Win condition (5-in-a-row): +50,000 points.
   - Block opponent 4-in-a-row: +15,000 points (two open ends) / +4,000 (one open end).
   - Double-threat forks (3-in-a-row with both open ends): +1,200 points.
   - Center-proximity bonus: Math.max(0, 10 - distance_to_center * 2).
4. Time-Attack Score Mode:
   A 60-second countdown timer runs concurrently with real-time recalculation of all
   consecutive 5-in-a-row lines on the board.

B. Sigma Slots: Las Vegas Casino Payout Mathematics
1. Reel Matrix: 4 rows x 5 reels (20 grid symbols per spin).
2. 20 Authentic Paylines:
   - Horizontal lines: Rows 0, 1, 2, 3
   - Diagonals: Top-left to bottom-right, bottom-left to top-right
   - V-shapes and Carets (^): Connecting corners to center reels
   - Waveforms and Zigzags: Connecting alternating rows across all 5 columns
3. Volatility & Return to Player (RTP) Balance:
   - Standard Fruits: Grape, Watermelon, Lemon, Pineapple, Plum (0.18x to 2.5x)
   - Premium Fruits: Dragonfruit, Banana (0.35x to 6.0x)
   - WILD Symbol: BIGBANANA (1.8x to 12.0x, substitutes for any standard fruit)
   - SCATTER Symbol: BIGWIN (4.0x to 30.0x jackpot payout)
4. Custom Wager Window:
   Direct wager editing via numeric text field or native modal dialog with full balance
   capping and validation.

C. Beer Snake: Dual-Mode Physics & Progression Curves
1. Level Progression: 25 structured stages. Players must collect 4 beer items per stage.
   Speed dynamically increases per stage:
   Delay(ms) = max(60ms, baseSpeed - level * 5ms)
2. Wall Collision Modes:
   - Solid Walls: Coordinate check (x < 0 || x >= cols || y < 0 || y >= rows) triggers
     immediate game over.
   - Pass-Through (Toroidal): Coordinates wrap seamlessly:
     x = (x + cols) % cols;
     y = (y + rows) % rows;

D. Bobr Minesweeper: Tactical Sonar & Guaranteed Safety
1. Safe First Click: The mine layout is dynamically populated only after the user's
   first click, guaranteeing that the first tile is always empty (0 adjacent mines)
   and triggers a flood-fill cascading reveal.
2. Sonar Radar Pulse: A unique tactical ability that scans a 3x3 radius and reveals
   hidden beavers safely without detonating them.
