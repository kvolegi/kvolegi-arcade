kvolegi arcade - Windows Edition
=================================
Author: kvolegi

HOW TO RUN:
1. Make sure Java (JRE or JDK 17, 21 or newer) is installed on your Windows PC (e.g. from https://adoptium.net).
2. Simply double-click:
   kvolegi-arcade.exe
   
   (Alternatively, you can also launch via run_windows.bat or run:
    java -jar kvolegi-arcade-windows.jar)

GAMES & FEATURES:
- Tic Tac Toe (Neon Edition) - Infinite board, 5 in a row, score system
- BeerSnake - Classic snake with neon glow and wall wrap/death toggle
- Bobr Minesweeper - Full neon design & custom difficulties
- SigmaSlots - Las Vegas casino math, fruit animations, custom bet input & Paytable
